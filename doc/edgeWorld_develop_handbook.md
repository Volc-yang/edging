# edgeWorld 开发手册

## 1. 引言

欢迎来到《易之世界》(edgeWorld) 的创世文档。本作不仅仅是一款游戏，更是一个遵循《易经》法则、在“周”、“连仙”、“灭世”三才循环中不断演化的生命体。本文档将阐述其核心哲学、独特的“定数”与“变数”轮回系统、创新的“降神”玩法，以及实现这一切的技术构想与开发规范。在这里，玩家既是世界的过客，也是角色命运的“降神者”。

## 2. 游戏概念

**中文名称**: 易之世界 (edgeWorld)

**核心灵感**:
“易之世界”是一款高度自由的开放世界角色扮演游戏（Open-World RPG），其核心世界观与框架的灵感源自中国古老的哲学典籍——《易经》。

**哲学内核**:
开发这款游戏不仅是技术实现，更是一次文化与哲学的探索。为了确保游戏世界的深度与一致性，我们确立以下哲学内核作为指导：

*   **以《易经》为纲**: 《易经》不仅是世界观的来源，更是我们设计一切系统的“行动大纲”。世界的演变（卦象更迭）、角色的命运（定数）、玩法的机制（变数）都将遵循其“变易、不易、简易”的核心思想。
*   **以“老庄”为魂**: 如果说《易经》是世界的骨架，那么道家“老庄学说”就是世界的血肉与灵魂。我们将用“道法自然”、“无为而治”的思想来填充世界的细节。例如，最强大的装备可能不是通过“刷怪”获得，而是通过在特定时间、特定地点“无为”地观察自然演变而“悟道”得来。NPC的行为逻辑也将体现“顺其自然”的特点，而不是机械地等待玩家交互。
*   **体验的“玄学化”**: 我们的目标不是生硬地灌输哲学概念，而是将它们“玄学化”、“游戏化”。玩家不需要读懂《易经》或《道德经》，但他们能在游戏中直观地感受到“无常”、“因果”、“天人合一”等东方神秘主义的魅力。玩家的行为和选择，将在一个看似随机但实则有内在逻辑的系统中，得到“玄之又玄”的反馈，从而引导他们自发地去思考和探索。

**世界构建**:
游戏世界将基于“三易”的宏大概念构建。“三易”即《连山易》、《归藏易》和《周易》。在游戏的背景故事中，《连山》与《归藏》大部分已失传，留下的残篇与现存的《周易》共同构成了整个世界的底层规则与秩序。

《周易》本身蕴含的几千字原文，虽简约但博大精深，它不仅是历史上诸子百家（如老子、孔孟）思想的源头，其哲学思想也深刻地投射在中国五千年的历史变迁、民间传说、中医理论乃至玄学文化之中。“易之世界”的目标，就是将这一深邃的文化符号转化为一个可探索、可交互、高度动态的虚拟世界。

**时代背景**:
游戏的历史由三个主要纪元构成一个“三才”循环，它们分别是：**周**、**连仙**、**灭世**。

玩家的旅程始于第一纪元——**“周”**。这是一个万物初始的纪元，既是上一个文明巅峰“灭世”后的新生，也是一个灵气稀薄、规则晦涩的“末法时代”。在这个时代，人类文明重归蒙昧，上古的辉煌已成传说。

尽管如此，“周”纪元并非一片死寂。世界依然遵循着基础的法则，正义与邪恶的碰撞从未停歇，隐秘的角落里也藏着凡人蜕变的机遇。在这个时代，每个人都是探险者。玩家将和其他人一样，仅能凭借着对《周易》有限而残缺的启示，在广袤的世界中探索，寻找上一个“灭世”纪元遗留下来的宝藏、知识与秘密。

**玩家与角色的关系：游客与降神**:
我们对玩家与游戏世界的关系进行了哲学层面的思考。游戏“易之世界”是一个遵循自身法则、不断演化的独立世界。而玩家，作为来自另一个世界的人，本质上是这个世界的“游客”，你无需对这个虚拟世界的最终命运负责。

然而，你所创建的“角色”并非游客。他/她是这个世界土生土长的一份子，其核心目标是在这个变幻莫测的世界中生存下去，并留下自己的印记。

基于此，我们提供了两种核心的游玩方式：

1.  **沉浸式体验 (Immersion)**: 你可以像传统RPG一样，长时间地沉浸在角色中，亲历他/她的每一次探索、每一次战斗和每一次成长，完整地体验“易之世界”的魅力。

2.  **降神式玩法 (God Descent)**: 这是一种更灵活、更具策略性的玩法。你可以选择进行一次短暂（例如几十分钟）的“降神”游玩。在此期间，你的每一个决策和行为都将高效地改变游戏角色的“定数”（主线命运），并累积其在世界中的“熵”（变数）。当你结束“降神”后，你的角色将带着你赋予他的新“定数”和“熵”，继续在这个世界中自主地生活和演变。在你离线的日子里，他可能会根据你设定的“惯性”获得奇遇、完成蜕变，甚至进入下一次“轮回”。

这种“降神”模式增加了游戏结果的“不确定性”，也允许玩家以一种“上帝视角”对角色的命运进行宏观调控，即使在没有大量游戏时间投入的情况下，也能深度参与到这个世界的演化之中。

**游戏类型与玩法**:
*   **类型**: 开放世界角色扮演游戏 (Open-World RPG)。
*   **核心玩法**: 玩家将在一个遵循“易”之法则的世界中探索。游戏的核心机制将围绕“变易”展开，例如：
    *   **动态世界系统**: 世界中的环境、气候、生态、社会关系、乃至任务线都会根据“卦象”和“爻辞”所代表的规则进行周期性或随机性的演变。
    *   **技能与成长**: 玩家角色的成长路径将不仅仅是线性的技能点分配，更可能与八卦、五行等概念结合，通过“悟道”或特定行为来解锁新的能力。
    *   **高度自由的叙事**: 故事线将是非线性的，玩家的选择会引发“爻变”，从而深刻影响个人命运、NPC关系乃至整个世界的走向。
    *   **“定数”与“变数”的轮回系统**: 为了提升游戏世界的深度和可重玩性，我们引入了“轮回”机制。这并非简单的重生，而是一套复杂的评判与演化系统：
        *   **定数 (Main Line)**: 在每一世开始或关键节点，系统会根据《易经》六十四卦衍生的64个维度对玩家的行为、选择和成就进行深度分析，从而构成一个“定数”。这个“定数”将决定玩家该次轮回的主线命运和核心挑战。
        *   **变数 (Side Quests/Dungeons)**: 玩家在世界中的行为会产生“熵”，即对世界秩序的扰动。这个“熵”值将作为“变数”，动态地为玩家解锁独有的副本、奇遇或隐藏事件。高“熵”行为可能会带来高风险的挑战和高回报的机遇。
        *   **核心算法**: 这套“定数”与“变数”的机制将是游戏的核心算法之一，通过复杂的模型推演，为每个玩家创造独一无二的游戏体验，并构成本游戏的核心技术壁垒。

**玩家目标**:
玩家的目标是多层次、且高度个性化的：
*   **短期目标 (生存与探索)**: 在“周”纪元的末法时代下生存下来，作为探险者，发掘上一个“灭世”纪元遗留的宝藏与秘密，并逐步揭开《连山》与《归藏》的真相。
*   **中期目标 (应“数”与改“熵”)**: 理解自身角色的“定数”，完成主线命运的挑战。同时，通过在世界中的行为主动或被动地改变“熵”值，解锁独特的“变数”奇遇与副本，体验由自己行为所催生的独一无二的剧情。
*   **长期目标 (悟“道”与降“神”)**: 玩家可以选择不同的终极追求。可以作为沉浸者，追求“顺天应时”，在一次次的轮回中体验不同的“定数”，最终理解“易”的终极法则，成为世界秩序的守护者。也可以作为“降神者”，通过对角色命运的宏观调控，尝试“逆天改命”，挑战世界的既定规则，甚至在某个纪元的终末，推动世界进入下一个循环，创造新的“易”之体系。

## 3. 艺术风格

游戏的视觉风格将紧密围绕“三才循环”的纪元设定展开，形成强烈的对比与演变感。
*   **周纪元**: 整体呈现一种“后启示录”式的原始与新生感。色调以大地色、石灰色和代表新生的绿色为主。建筑风格是蒙昧初开的聚落，混合了少量从“灭世”纪元遗迹中发掘的、无法被完全理解的高科技或仙法残留物。光照和氛围强调自然与神秘感。
*   **连仙纪元**: *(待补充) 设想为一个能量充沛、仙法与科技并存的鼎盛文明时期，视觉上可以更加华丽、奇幻。*
*   **灭世纪元**: *(待补充) 设想为一个冲突与毁灭的时代，可能充满战争的疮痍、能量的失控与崩坏的美学。*

整体上，艺术风格追求将中国古典哲学意象（如阴阳、五行、八卦符号）不着痕迹地融入到环境、建筑、角色和UI设计中。

## 4. 游戏技术实现原理和成本分析

本章节旨在初步探讨核心游戏系统的技术实现思路，并对其开发及运营成本进行高阶评估，以回答关于其可行性的几个核心问题。

### **1. 如何搭建一个循环的、不会崩塌的世界？**

要构建一个能自我循环、长期稳定运行的开放世界，核心在于**“收敛”**和**“重置”**两大机制。

*   **收敛 (Convergence)**: 即使世界状态（由64卦代表）和玩家行为（熵）是动态变化的，但系统的规则必须是收敛的。这意味着世界的演变不能是无限发散的，否则将产生指数级的计算复杂度和内容需求。
    *   **技术实现**: 我们可以为世界定义一个“总熵”值。当玩家行为和随机事件导致“总熵”过高，接近系统崩溃的临界点时，系统会强制触发“收敛事件”（例如，天灾、战争、一位“圣人”的出现），这些事件会大幅降低世界熵，将世界拉回到一个相对稳定或不同的状态。这在叙事上对应了“天下大势，合久必分，分久必合”。

*   **重置 (Reset)**: “三才循环”是最终极的重置机制。
    *   **技术实现**: 当一个纪元（如“周”）发展到其终极状态（无论是极盛或极衰），服务器将触发“纪元更迭”事件。这并非简单的清空数据，而是一个复杂的迁移过程：
        1.  **结算**: 对当前纪元所有玩家的成就、状态进行最终“定数”分析。
        2.  **继承**: 根据结算结果，将一部分关键信息、角色的“道果”或解锁的“血脉”等，以某种形式继承到下一个纪元的新角色身上。
        3.  **创世**: 服务器根据下一个纪元（如“连仙”）的初始规则集，重新生成世界地图、NPC、势力和基础任务。
    *   **健壮性**: 通过这种方式，世界不会无限膨胀，而是在三个纪元间循环往复，保证了系统的长期稳定性和可玩性。

### **2. 如何在这个世界构建"易之法则"？**

“易之法则”是世界的底层驱动力。它由两套核心理论共同构成：描述世界【生成与演化】的“道生一”模型，和描述世界【结构与组成】的“太极生八卦”模型。



**演化规律：道生一**

*   **道生一 (能量守恒)**:
    *   **原理**: “道”即是“一”。我们设定游戏世界是一个封闭系统，其内部的“总能量”是恒定为1的守恒量。
    *   **技术实现**: 在服务器端，定义一个全局的、不可变的总能量常量。世界的一切演化，都是在这个总能量约束下的此消彼长。

*   **一生二 (阴阳相生)**:
    *   **原理**: 总能量“一”分化为“阴”与“阳”二气。世界万物（包括角色、生物、物品、乃至一个地点）都由不同比例的阴阳二气构成。不存在绝对的纯阴或纯阳，“孤阴不长，孤阳不生”。
    *   **技术实现**: 任何一个游戏对象（Entity）或世界空间的一个地块（Tile），其核心数据结构中都包含 `yin_qi` 和 `yang_qi` 两个属性。其总和受到上一层能量的约束。例如，一个地块的总能量为 `e`，则其 `yin_qi + yang_qi = e`。

*   **二生三 (生灭循环)**:
    *   **原理**: “三”并非一个具体的“事物”，而是一个所有事物都必须经历的**过程**。阴阳二气的持续互动，必然导致任何事物都要经历**“初生、鼎盛、衰败、消亡”**的四阶段生命周期。
    *   **技术实现**: 为每一个游戏对象（Entity）内置一个四阶段状态机（Four-Stage State Machine）。状态的变迁由其自身的阴阳二气比例、以及与环境的阴阳二气交换情况决定。
        *   **初生**: 当一个区域的阴阳二气达到某种“和谐”的比例，新的事物（例如一棵树、一只鹿）就可能诞生。
        *   **鼎盛**: 事物通过与环境进行能量交换（吸收、转化），维持自身内部的阴阳动态平衡，并成长。
        *   **衰败**: 当内部平衡被打破，或受到环境的剧烈冲击，事物开始走向衰败。
        *   **消亡**: 事物“死亡”，其构成自身的阴阳二气被释放，回归到世界的大循环中。

*   **三生万物 (涌现复杂性)**:
    *   **原理**: 无数的游戏对象各自经历着自己的微观生命周期，它们之间的相互作用和能量交换，将共同“涌现”出复杂、多变、不可预测的宏观世界现象——即“万物”。
    *   **技术实现**: 这依赖于一个高性能的、基于实体组件系统（ECS, Entity Component System）的服务器架构。服务器不预设剧本，而是持续地模拟成千上万个实体的独立生命周期和交互规则，让“故事”自然发生。
**宇宙组成：太极八卦**

世界的静态结构和属性，则遵循“太极生两仪，两仪生四象，四象生八卦”的分类模型。我们将“宇宙”一词拆解为“宇”和“宙”，并赋予其游戏中的具体含义：

*   **宇 (空间) = 八卦 (The Eight Trigrams)**
    *   **原理**: “宇”代表上下四方，即整个世界的空间结构。八卦（乾、坤、震、巽、坎、离、艮、兑）分别对应了世界中八种最基本的空间元素和方位属性。
    *   **技术实现**: 在进行程序化世界生成时，每个区域（Biome）或地块（Tile）都会被赋予一个或多个八卦属性。这个属性决定了该空间的地形特征（如“艮”为山）、环境效果（如“离”为火，气候炎热）、特有资源和生物。

*   **宙 (时间) = 四象 (The Four Symbols)**
    *   **原理**: “宙”代表古往今来，即世界的时间维度和周期性规律。四象（少阳、太阳、少阴、太阴）则代表了时间流转的四个阶段。
    *   **技术实现**: 整个游戏世界存在一个全局的时间轮转系统，该系统以“四象”为周期进行循环，可以对应为游戏中的四季或更长的时代节律。世界的时间状态会从“少阳”（春/初生）发展到“太阳”（夏/鼎盛），再到“少阴”（秋/衰败），最后进入“太阴”（冬/寂灭），周而复始。全局的时间状态（“宙”）将与特定区域的空间属性（“宇”）相结合，共同决定该时该地的最终样貌和事件。例如，一个“艮”（山）属性的空间，在“太阴”（冬）的时间里，可能会引发大雪封山、野兽冬眠等事件。

### **3. 这个世界的仲裁机制是怎么样的？**

仲裁机制分为**宏观的世界层面**和**微观的玩家个人层面**。

*   **宏观仲裁 (世界层面)**:
    *   **机制**: 即上述的“动态世界系统”。世界的“总熵”是主要的仲裁指标。当世界过于混乱或过于死寂，系统会通过触发“收敛事件”或最终的“纪元更迭”来进行宏观调控，这是世界的“天道”，不以单个玩家意志为转移。

*   **微观仲裁 (玩家层面)**:
    *   **机制**: 即“轮回系统”。这是对玩家个体行为的因果报应（Causality）机制。
    *   **“定数”的仲裁**: 你在上一世的行为，通过64维向量分析，直接“仲裁”了你下一世的核心命运。例如，上一世杀戮过重，64维分析结果偏向“剥”卦，下一世的“定数”可能就是“家道中落，孤苦伶仃”的开局。
    *   **“变数”的仲裁**: 你在当前世界的行为所产生的“熵”，实时地“仲裁”了你将遇到的奇遇。例如，你拯救了一个重要NPC，产生了正向的“熵”，可能会为你解锁一个关于报恩的“变数”副本。

### **4. 这样的世界运行成本怎么算？**

运行成本主要分为**服务器硬件成本**和**数据存储成本**，两者都与核心玩法的实现方式强相关。

*   **服务器硬件成本**:
    *   **主要开销**: CPU计算。尤其是“降神”玩法中的AI代理离线模拟，以及“动态世界系统”的规则演算。
    *   **估算模型**: `成本 ≈ (单个AI代理的平均CPU消耗 * 平均离线玩家数量) + (世界状态演算的CPU消耗) + (基础API服务的CPU消耗)`。
    *   **优化策略**:
        *   **离线模拟降频**: 离线AI的模拟不需要实时进行，可以以较低的频率（例如每几分钟一次心跳）进行，大幅降低计算量。
        *   **分区计算**: 开放世界可以分区（Sharding），每个服务器实例只负责一部分区域的AI模拟和事件演算。
        *   **云计算弹性伸缩**: 在玩家活跃高峰期（如晚上和周末）增加计算实例，在低谷期减少，以优化成本。

*   **数据存储成本**:
    *   **主要开销**: 玩家行为日志。为了实现精确的“定数”分析，需要记录玩家大量的关键行为。
    *   **估算模型**: `成本 ≈ (单个玩家平均每日产生的日志大小 * 活跃用户数 * 存储周期)`。
    *   **优化策略**:
        *   **数据聚合**: 无需记录所有鸡毛蒜皮的操作。只记录对“64维向量”有影响的关键行为，并在记录时就进行初步的分类和聚合。
        *   **冷热数据分离**: 近期的、用于实时计算“熵”的数据存放在高速缓存或数据库中（热数据）。而用于周期性“定数”分析的长期历史数据，可以归档到成本更低的存储服务中（冷数据）。

## 8. 构建与运行

### macOS

1.  在 Xcode 中打开 `edge-world.xcodeproj`。
2.  选择 `edge-world macOS` scheme。
3.  点击“运行”按钮。

或者，通过命令行操作：

```bash
xcodebuild -scheme "edge-world macOS" build
open build/Debug/edge-world.app
```

### iOS / tvOS

1.  在 Xcode 中打开 `edge-world.xcodeproj`。
2.  选择 `edge-world iOS` 或 `edge-world tvOS` scheme。
