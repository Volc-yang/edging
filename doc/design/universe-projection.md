# U7：UE 写实与时间投影设计

## Plan：输入和已证明边界

- **已定：**[U 架构树](../universe_architecture_design_plan.md)要求 UE5 发布版插件/适配优先，4D 权威单写、观察不推进世界。Seed→Tree 是抽象因果发展，非植物；万物有灵不等于每个可见三角形、UE Actor 或流送 cell 都有独立权威身份。
- **已接受设计输入：**[U1](universe-identity.md)区分 `WorldId/ExistenceId/RelationId/ProjectionId`，逻辑 tick 与 revision 不应被生产设计强制相等；[U5](universe-origin.md)提供丰富混沌六类场所和候选连通图。具体接壤、六区实际通行、水文与灵域规则尚待裁决。
- **已有有限观察：**[H6C 复核](../evidence/home-visitor-independent-acceptance/coordination-review.md)接受准确 Mac/Metal 开发入口的可访代理、0→1→2、只读和恢复；不接受写实、性能、PIE/打包/跨平台或原默认退出可靠性。H6C 原始运行身份为 `f674483`，不是本设计基线的新运行。
- **源码观察 @ 本基线：**`EdgeWorldCausalActor.cpp` 禁用 Actor Tick，用 BasicShapes 从已验证观察重建节点/边；`EdgeWorldCausalGameMode.cpp` 经 HeadGate 后应用观察与 HUD。`ChaosRealismTerrain.cpp` 是程序网格/水面代理，曾隔离与 seed7 无关的模板 Landscape；`.uproject` 显式启用 Runtime 与 ProceduralMeshComponent。[旧写实计划](../chaos_realism_01_plan.md)记载 Water 实验边界。这些不证明下表所有发布版能力已经启用或通过验收。

**目标：**形成可交给 U4/U6/U8/U9 评审的状态→几何/资产/碰撞/流送映射，支持当前或历史切片可追溯呈现。一步只设计一个有限样区，不承诺完整星球、无限世界或真实生态。资源预算为一份设计与至多两轮定向修订；不启动 UE/Genesis/GPU、不下载资产、不调用模型或付费工具。

## Do：发布版能力比较与建议路线

下表是技术候选，不是 UE 5.8.3/当前 Mac 的已验证能力清单。任何选项实施前都绑定准确引擎 build、Mac 型号/GPU、Metal feature level、插件版本、运行/打包目标、资产和渲染配置；当前缺少逐项实测，不能以“使用 UE5”推定支持或性能。

| 发布版能力 | 适用范围 / 设计建议 | 风险、替代与未验证项 |
| --- | --- | --- |
| Landscape | 编辑器制作有高度/材质层的有界地表；同一初态可离线生成内容，再将变化作版本化覆盖 | 不能假定任意运行时创建/编辑接口可用于发行版；先比较编辑器预制与 ProceduralMesh 运行时适配，不修改引擎 |
| World Partition / HLOD | 在规模实测需要时分块流送地形/建筑，HLOD 只降低远景成本 | cell/Actor 加载不是存在生成，卸载不等于消亡；HLOD 必须对应同一内容/时间版本；当前小场景不强制引入，Mac cook/流送内存未验 |
| Nanite | 候选高密度静态岩石/建筑；按网格和材质逐项选择 | 不预设本机/所有资产类别/位移或植被路径可用；不可用时采用普通 StaticMesh + LOD，保留同样语义与碰撞边界 |
| Lumen / 其他发布版光照 | 动态间接光/反射候选；保持曝光、太阳与材质参考可比较 | Mac 的软件/硬件路径、质量与帧时间须分别实测；可先用明确记录的动态直射/天空光/反射方案，不把替代光照当 Lumen 已通过 |
| Water / 水面材质 | 海洋、河道、河泽的可视水体与岸线候选 | 旧计划记为 Experimental；接口/打包需验证。可用已版本化网格/材质表达水面；波浪不是水文学求解，不由 Water 自行提交 Genesis/权威状态 |
| Foliage / 实例化 / PCG | 授权植物/石块实例及可重建密度分布；优先从已提交清单派生 | 不从本地随机/帧数生成权威植物；PCG 如引入要固定版本/输入和随机源。材质风摆是展示，不等于生命演化；碰撞代理独立评审 |

**推荐 proposed：**先保留现有发布版宿主与严格观察校验，在一份有界初态清单上做可替换资产投影；连续地表可先编辑器预制或程序网格，按证据选定。World Partition/HLOD、Nanite、Lumen 和 Water 均按需求逐个进入小探针，不把全部插件启用视为写实方案。没有已批准契约的可复现发布版缺口，不提出引擎源码改造。

### 观察身份与投影事务（候选逻辑契约，非新 wire）

建议 `ViewBinding` 保存 `world_id, requested_tick, source_revision/watermark, state_hash, event_hash, schema_version, rule_version, origin_manifest_ref, region_refs, projection_version, unit_transform_version, asset_manifest_hash`；U4 冻结实际编码、水位语义和旧 `ruleset_version` 的映射。`ProjectionId` 以世界内存在/关系或地理引用关联可重建实例，不从 Actor 名或流送路径反推权威身份。UE 使用 cm；Genesis/地理单位、坐标轴、原点和方向的转换须由 U2/U4 版本化提供，禁止凭画面猜换算。旧图 `x=200 cm/tick`、`y=influence_mm` 只是技术图布局，不是物理单位映射。

| 输入与所有者 | U7 的纯投影结果 | 禁止的反向行为 |
| --- | --- | --- |
| U5 已提交起源清单/地理引用 | 高程/水域/建筑/植被语义对应地形与资产集合；无独立存在的装饰仍可展示 | 根据贴图或 PCG 结果给场所分配灵域/规则 |
| U1 存在状态/关系 + 同一提交的因果引用 | 稳定 ID 对应网格、材质参数、状态标识与可查询来源；HUD 同时显示 head 与 viewed tick | 由材质颜色或 Actor Tick 决定状态、增加事件或推进世界 |
| U2 已提交物理样本/配置引用 | 经版本化单位转换呈现位置/轨迹；区分已提交样本与实验/候选 | 在 UE 再跑一份可写物理权威，以落点/碰撞替换 Genesis 结果 |
| U6 本地访客/会话 | 本地观察相机与导航碰撞；有世界因果作用的输入另走权威命令 | 把 CharacterMovement/Chaos 本地接触隐式变为世界事件 |

候选接收顺序：①锁定请求身份与本地 view generation；②校验完整样本 world/时间水位/规则/状态及引用；③准备资产和区域块，检查版本/授权/碰撞来源；④在 UE 游戏线程统一切换可见集合、碰撞集合和 HUD 的 `ViewBinding`；⑤销毁/缓存旧投影。加载失败或部分就绪时保留最后完整有效切片并明确显示加载/错误，不能用另一世界/另一 tick 的块填洞。旧异步请求晚到只可丢弃或缓存，不能覆盖更新的选择。这里的“投影事务”只改本地可重建表现，不是第二个世界提交点。

### 当前、历史、流送与碰撞

- **proposed：**一次活动视图只绑定一个准确已提交切片。跨 cell 流送按 `(ViewBinding, region, asset/content version, quality profile)` 复用缓存；引擎/平台相关派生资源另带 build/profile，不能复用错误 cook。距离可改变 LOD，不能改变权威状态或历史取样时刻。HLOD/地形/植被替代物必须保持来源可追溯。
- 历史观察不调用 Genesis、不执行演化规则，不通过逐帧“倒放物理”重建过去。推荐首版历史模式只读巡视：本地导航暂停或使用同切片已验证碰撞集合，禁止拿当前 head 的障碍与历史画面混用；具体控制交给 U6。恢复当前视图前先装齐当前切片并核对安全进入点，不新增访客 pose 持久化契约。
- 纯展示水波/风摆/过渡动画使用独立本地展示时钟，暂停/重启不得改变权威。若动画表达一个状态转移，标明其为已提交前后态的视觉插值，显示来源水位；不能在插值中对玩家开放尚未存在的权威对象。植物几何仍只是投影，不能因“长大动画播完”自动生成世界发展事件。
