# U5｜丰富混沌初态设计

版本：v0.1；父节点 U；状态：**设计提案，待独立审查**；基线 `5a5fe11fc2c452de2aace7e8cc7c05d2fe5834c9`。本卡只定义下一阶段可评审的初态清单和有限样区，不批准新的宇宙规律，也不声称产品运行门通过。

## Plan：语义、范围与证据等级

**已定（用户与 G0）：**初始混沌世界有城市、蛮荒、原野、森林、海洋、河泽。混沌不是空无，而是丰富形态已有、独立灵域身份与归属及演化规律尚未分化。世界空间不限定方块。世界内玩家化身属于世界之灵；账号身份与化身须分离。Seed→Tree 是抽象初态受因果影响发展成结构，Genesis 属现有纵切必需路径；这些不表示初态里的树木必须服从一条已定植物规则。

**已观察（旧 P0 实验）：**`edgeworld.chaos-origin.v1` 的 seed 7 清单有六类各一处、河道和一条 `city → plain → forest → river_marsh → ocean` 路线；蛮荒单独可见，**不在该路线**。tick 0 的 `world_spirit_id=null`，显式 O1 才提交整体之灵边界。固定 seed 7 的代理视觉检查能辨认场所和路线，不能证明写实质量、正式地理规律或六区遍历路线。旧 TWO 和八卦提案没有由此获批。来源见 [P0 契约](../chaos_origin_contract.md)、[生成器](../../engine/chaos/world_generation.py)及[视觉复核](../evidence/chaos-pdca-02/visual-retest.md)。

**本卡提案：**在有限、连续、可步行观察的样区里组织六类场所。具体接壤、水流方向、通行路线、地形尺度和过渡带均为待审设计；任何一项都不能在实现时暗升为宇宙法则。U1 负责身份语义，U7 负责 UE 投影，U5 只拥有起源清单的形态与生成输入提案。

候选生成顺序：①固定 `world_id/seed`、生成器及清单 schema 版本；②生成有界地形、水域和六类场所的地理引用；③校验场所范围、闭合轮廓、交叠优先级与路线/水系引用；④加入仅作为候选输入的环境量；⑤规范编码并提交清单摘要；⑥ UE 按已提交清单和投影版本重建表现。初始化与后续因果提交的事务边界、历史保存及恢复由 U4 定义；本卡不让投影端写权威状态。生成失败不得留下被误读为已提交的部分世界。

### 固定 seed 示例：旧实验 fixture，不是目标宇宙地图

`world_id=chaos-demo`、`seed=7`、范围 `[0,0,100000,100000] cm`，`schema=edgeworld.chaos-origin.v1`，`generator=chaos-geography-exp-v1`。六处的 `place_id/kind` 分别为 `city-1/city`、`wildland-1/wildland`、`plain-1/plain`、`forest-1/forest`、`river-marsh-1/river_marsh`、`ocean-1/ocean`。`river-1` 点序为 `(40000,55000) → (60000,40000) → (80000,40000)`，经过河泽，末点在海洋。`origin-route-1` 点序为 `(15000,15000) → (35000,20000) → (45000,40000) → (60000,40000) → (80000,40000)`，按序关联城市、原野、森林、河泽、海洋；蛮荒位于该样区另一位置，可另设观察支线。清单规范摘要为 `75f6c3d719e9e0afefb64e582750cf9fcc70e932fe1192886abdc99e78d91da3`。这些坐标和摘要只固定旧实验接口，不决定新世界的大陆比例或水文规律。

### 下一阶段连续样区拓扑提案

以一处可步行/载具观察的局部样区为设计单位：城市接原野，原野经林缘接森林，森林有通往蛮荒的支线；河泽与森林/原野之间有湿地过渡，河道穿过河泽并在海洋排出；海岸连接河泽与海洋。主线可沿旧五区路线验证兼容性；**新增六区支线属于设计提案，未实测、未批准**。连续性是可达关系，不要求六个多边形两两直接接壤。水路拓扑只声明河泽节点在出海口之前，不从平面折线推断真实水位、流速或重力方向；这些必须由地形高程和 Genesis/水体契约另行验证。

```text
城市 ─ 原野 ─ 森林 ─ 河泽 ─ 海洋
         \      │       │       ↑
          └── 蛮荒（候选支线）   河道出口
```

图仅表达候选可达性。正式路线图需给每段地理接点、通行条件、障碍和观察点；若新样区无法做到，局部改图，不修改已获验证的旧 fixture。
