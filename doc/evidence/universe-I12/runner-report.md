## Implemented boundary

Default plan never launches. `run` requires root's actual private R12 card, independently
supplied card SHA256, exact accepted **product** source SHA40, explicit initialize/existing
slot and `--execute`. Tool worktree source is different from product source: current tool
branch's old launcher must not be used for actual R12. Product must contain the actual accepted
normal I10/I11 merges (including PR97/100); root binds its exact final SHA and launcher hash.
No card or real owner inputs were generated by this implementation.

Before runtime, source status rejects every tracked modification, verifies each precisely
allowlisted output readlink/target or generated-file hash/provenance, and rejects unknown
untracked paths. It does not broadly ignore untracked files. Deployment requires persistent
DevSSD canonical targets, private owner metadata, four exact public input pins and actual
owner indirect refs cross-checked against those same pins. Mode, world/root/context/key/session
must match; expected B/O record digests are independently recomputed. Owner metadata is parsed
for these checks, not copied/logged; no private key file is opened. Scratch is isolated. Root
must preplace the five output mappings and the persistent input bundle; runner does not do so.

The supervisor owns one actual launcher Popen and its parent wait result throughout the session.
Known accepted launcher argv is fixed (`--launch --viewport-preflush --universe`, private owner
path, isolated user directory; only initialize adds `--universe-initialize`). Accepted launcher
does the build/-NoUBA internally. No arbitrary commands or environment programs come from JSON.
Build/startup/interaction/shutdown and whole-session/two-session time/byte budgets are monitored,
including failed-attempt accounting explicitly carried by root's card. Default UI is untouched;
future CUA tools alone perform real actions/images while this supervisor stays alive.

Failure cleanup first uses our actual Popen handle, then only observed descendant PID/start/argv
identities revalidated before signals. No authority-path/global kill search. All forced cleanups
are failures. Logging errors use best effort and finally still performs cleanup and true wait;
secondary close failures preserve the original error. Live byte accounting tolerates only lstat
FileNotFound from atomic Store rename, never permission errors, symlinks or nonregular files.

Preliminary exit receipt is always `normal=false`. Receipt and full seal are written before
completion accounting. Final completion charges ceil(measured post-seal time)+2s conservatively
for its own write/audit, computes exact completion JSON bytes by fixed point, then audits actual
time/bytes before publishing. If audit/budget fails there is false or no completion. Existing
session uses only same-card/source normal completion plus HEAD, not an early receipt. Final
charged cumulative time includes first-session sealing. Every completion remains supervision,
not G-B2. The complete card/API/operational details are in [runner-contract.md](runner-contract.md).
