## Plan：版本化测量契约

G0 先冻结目标机器、引擎 build、场景、分辨率、负载、路线、采样窗口、有效样本比例、CPU/GPU/内存阈值及预算。GQ 可在此之前设计采法与采集一次**无 pass/fail 裁决的基准**。每次运行生成不可复用的 `run_id`，记录如下字段：

| 类别 | 必填内容 |
| --- | --- |
| 源与构建 | Git SHA、脏工作树标记、UE 版本/CL、插件 SHA、编译配置、构建日志 SHA256 |
| 环境 | OS/build、CPU/GPU/内存、Metal/RHI、显示与实际渲染分辨率、VSync/FPS 限制、电源/热状态、后台负载摘要 |
| 世界输入 | 场景/地图、seed、初态 canonical hash、Worker 版本、Genesis/AI 版本（若纳入）、资产清单及每项来源/许可/哈希 |
| 执行 | 操作脚本版本、相机路线、预热与测量起止时间、样本数、退出码、异常、权威前后摘要 |
| 原始证据 | 原始 CPU/GPU trace、完整 UE/Worker 日志、截图/录像和各文件 SHA256、绝对路径及采集工具版本 |
| 裁决 | G0 门版本、计算脚本版本、有效样本比例、逐次 p50/p95/max 和缺样说明、独立 reviewer、结论 |

原始文件使用独立输出根的 `runs/<run_id>/raw/`；只追加索引和摘要，禁止覆盖原始 trace。提交到 Git 的是小型 manifest、哈希和审查报告；大文件保留在可访问的证据卷，记录留存期限与备份责任人。绝对路径只是当前本机定位符，跨机器复核需另给共享位置或受控拷贝及哈希。

## Do：下一张执行卡的有限步骤

1. 统筹分配独占 UE/Worker/GPU 与证据目录，固定 G0 场景脚本、预算及阈值版本；采集前保存环境和构建身份。
2. 在 UE 5.8.3 发布版 Metal 运行固定场景，用 UE Unreal Insights/CSV profiler 的可用 CPU 帧信号和 Metal GPU frame timing 信号同时采样；先作短探针，确认两种信号可按同一时间窗导出。具体工具命令和计数器名称须在该机探针中核对并写入 run manifest，不能凭设计文档假称工具可用。
3. 按冻结预热、时间窗和重复次数分别启动独立 run。保存未过滤 trace、完整日志、截图、权威摘要和采集失败信息。每次运行后单独算样本有效率和 CPU/GPU p50/p95/max，保留计算代码及其版本。
4. 独立 reviewer 从索引随机抽取原始文件，复算 SHA256、样本统计和场景身份，并对照 G0 门逐项裁决。素材清单逐项检查来源、授权范围、改动方式和项目分发许可；程序代理也须记录其引擎内置或自制来源。
