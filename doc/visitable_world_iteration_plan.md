# 可访问世界纵切：PDCA 方案树

状态：2026-11-01，v0.1 统筹方案。基线 `f5532e6`。本轮把总目标“人类能登陆、游玩、重访的持久 4D 数字宇宙”推进到一个可邀请人进入的有限场景。Seed→Tree 在此仍指抽象初态经因果影响形成结构态，不指植物。Genesis 物理为必需路径；AI 提案与载具登陆保留在总目标，不作为本轮门。UE5 发布版优先，权威世界只有 worker 提交；视觉、相机、历史观察纯读。

## 根节点 V-HOME

**Plan：**让访客在 UE 中进入一个有空间感、可导航、可观察 tick 0/1/2 因果发展的场景，退出后可从同一世界状态继续。当前三节点两边黑底图是技术基线，不是完成的世界。空间、光照、材质和导航可作为可替换的 UE 表现层；任何新的演化规律、物理量或权威拓扑须先回 S0/S4 裁决。目标 Mac/分辨率、授权资产、写实参考和性能阈值尚未冻结，画质与性能只能记录观测值，不能宣称产品通过。

**Do：**沿下列 DAG 交付独立任务。每张写入卡从准确集成 SHA 建 worktree、独立 PR；主任务负责接口裁决、集成、上下文与提交。

```text
V-HOME
├─ H0 场景体验与门定义 ─────┬─ H2 UE 可访空间/观察层 ─┐
├─ H1 G3 退出路径复核 ─────┤                      ├─ H4 集成演示 ─ H5 独立体验与恢复验收

└─ 现有 G2/G3 因果纵切 ────┴─ H3 因果叙事/证据 HUD ┘
```
